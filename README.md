# 3Dキャラクター装備 ＆ ステータスUIビューアー（MVP / UniRx）

Unity（uGUI）と **UniRx** を用いて、**MVP（Model-View-Presenter）アーキテクチャ** に基づき設計した、3Dモデル連動型の装備切り替え・ステータス表示UIデモ作品です。

## 主な機能
- **Render Textureを用いた3Dモデル表示**: UIフレーム内に3Dモデルを表示。
- **ドラッグによる3Dモデル360度回転**: `IDragHandler` / UniRx を用いた操作変換処理。
- **UI一覧の動的生成**: データリストから `ScrollRect` へ要素を動的生成・配置。
- **ステータス動的更新**: 選択した装備に応じたステータステキストのリアルタイム更新。
